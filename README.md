# LamraLux

I want you to create an e-commerce headless website, named "ale LifeStyle" (The logo is the image inserted) that starts with a door in the very beginning (The website visitor click on the door like in the inserted photo to open to be taken to the platform)

Navigation menus :
- HomePage : where differents items from different section will appear to the visitors
- Self-care 
       * Tondeuse
       * Pack de soin/SPA
       * Articles de massages
- Fragrances
      * For Men
      * For Women
- Air Diffusers
- Watch
      * For Men
      * For Women
- Why Us
- Contact Us

I want an elegant an simple website that make the visitors feel comfortable to be in. 
For the payments, the visitors will have 2 choices :
1- Online payment (with 10% OFF automatically)
2- Offline/Cash-On-Delivery
